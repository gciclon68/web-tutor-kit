que explica el sitio

Reemplazá este texto. Este es un sitio multipágina navegable: panel izquierdo para saltar entre módulos, panel de páginas dentro de cada módulo, tema oscuro por defecto, paneles ajustables, y un tutor de Claude Code embebido.

1 Módulo 1De qué trata este módulo · N páginas →
Cómo navegar. Panel izquierdo = módulos. Dentro de cada módulo, panel derecho = páginas (clic, botones ◀ ▶ o flechas ← →). Arrastrá el borde del panel izquierdo para ajustar su ancho. Botón Tutor abajo a la derecha para chatear con Claude Code.

Para el tutor: node chat-server.js (o doble clic en iniciar-tutor.cmd) y abrí http://localhost:8770.
