02 · Ejercicio 2·a (0.5 pt)

Combinación lineal de soluciones = solución

Si Ψ₁ y Ψ₂ cumplen Ψᵢ′ = A(t)Ψᵢ, entonces αΨ₁ + βΨ₂ también es solución, para todo α,β ∈ ℝ.

  1. Nombrar el candidato

    Sea Ψ = αΨ₁ + βΨ₂. Queremos ver que cumple Ψ′ = AΨ.

  2. Derivar (la derivada es lineal)

    Ψ′ = (αΨ₁ + βΨ₂)′ = α Ψ₁′ + β Ψ₂′

  3. Usar que cada una es solución

    Ψ′ = α(AΨ₁) + β(AΨ₂)

  4. Sacar A de factor común

    Ψ′ = A(αΨ₁ + βΨ₂) = A·Ψ  ∎
    El conjunto de soluciones es un espacio vectorial: linealidad + factor común A.
03 · Ejercicio 2·b (1.0 pt)

…pero NO necesariamente fundamental

Ser solución (Ψ′=AΨ) y ser fundamental (además det Ψ ≠ 0) son cosas distintas. Una combinación sigue siendo solución, pero su determinante puede anularse.

Contraejemplo: dos fundamentales cuyas columnas pueden alinearse.

αΨ₁+βΨ₂ = αββα
det = α² − β²

Se anula en α = ±β: las columnas se vuelven paralelas y el paralelogramo colapsa.

det (área con signo)—
Estadofundamental
Frase para el examen. “La combinación es solución por linealidad (2·a), pero no necesariamente fundamental: basta que exista (α,β) con det(αΨ₁+βΨ₂)=0. Fundamental exige determinante no nulo para todo t.”
04 · Ejercicio 2·c (0.5 pt)

Φ = ΨM con M invertible sí es fundamental

Si Ψ es fundamental y M ∈ ℝⁿˣⁿ es invertible y constante, entonces Φ = ΨM es fundamental. Ojo: M multiplica por la derecha.

  1. ¿Es solución? — Derivar (M constante)

    Φ′ = (ΨM)′ = Ψ′M = (AΨ)M = A(ΨM) = AΦ solución ✓

  2. ¿Determinante no nulo? — Producto de determinantes

    det Φ = det Ψ · det M ≠ 0
    Ψ fundamental (det Ψ≠0) y M invertible (det M≠0). fundamental ∎
Significado. Multiplicar por la derecha por M constante invertible = recombinar las columnas (cambiar la base) sin salir del mismo espacio. Por eso todas las fundamentales cumplen Φ = ΨM. Con M = Ψ(t₀)⁻¹ obtenés la que vale I en t₀: Φ(t,t₀) → puente al Módulo 3.
05 · El salto a variante en el tiempo

Armar Ψ(t) del Ejercicio 3 A(t) variable

Con A dependiente de t no hay retrato fijo ni autovalores constantes. Pero el sistema es triangular superior → se resuelve por integración directa por componentes, de abajo hacia arriba.

A(t) =2e−t01⇒ẋ₁ = 2x₁ + e−tx₂ ; ẋ₂ = x₂

  1. Ecuación de abajo (desacoplada)

    ẋ₂ = x₂ → x₂ = c₂ eᵗ.

  2. Sustituir arriba

    ẋ₁ = 2x₁ + e−t(c₂eᵗ) = 2x₁ + c₂ → ẋ₁ − 2x₁ = c₂.

  3. Resolver esa lineal

    Homogénea c₁e²ᵗ, particular −c₂/2 → x₁ = c₁ e²ᵗ − c₂/2.

  4. Extraer las dos soluciones base

    (1,0): e²ᵗ0   (0,1): −½eᵗ

  5. Columnas → Ψ(t)

    Ψ(t) =e²ᵗ−½0eᵗ

  6. Verificar con el Wronskiano

    det Ψ(t) = e²ᵗ·eᵗ − (−½)·0 = e³ᵗ ≠ 0 fundamental ✓
    Abel: tr A = 2+1 = 3 → det crece como e³ᵗ.
Lo importante. En LTI armabas Ψ con autovalores de una A fija. Acá la A cambia: la receta pasa a ser integrar aprovechando la estructura triangular. Esta Ψ no vale I en 0 (Ψ(0)=[[1,−½],[0,1]]); normalizarla es el Ejercicio 3·a → Módulo 3.
06 · Orientación al examen

Qué te van a pedir sobre Ψ

Patrón de examen · reflejos
  1. “Demostrar que … es solución” → derivá el candidato, usá Ψᵢ′=AΨᵢ, sacá A de factor común. (2·a, 2·c)
  2. “Solución vs. fundamental” → recordá el det ≠ 0. Solución es cerrado por combinación lineal; fundamental exige Wronskiano no nulo. (2·b)
  3. “Hallar una matriz fundamental” con A(t) triangular/desacoplada → integrá por componentes de abajo hacia arriba, formá columnas, verificá con el Wronskiano.
  4. Chequeo siempre disponible: det Ψ(t) = det Ψ(t₀)·e∫ tr A(s) ds (Abel–Liouville).
